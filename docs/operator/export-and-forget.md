# Export and forget a person

Two things somebody can ask you for, and both are on their account page:
[Users](users.md) → **edit** the person.

**Take the copy first.** Once they are forgotten it cannot be built.

## Export everything about this person

**Export everything about this person** downloads a tar archive holding: their
wiki, the facts other people's wikis hold **about** them with who said each one
and when, the files they uploaded, and their identity card.

## Forget this person

**Forget this person** opens a confirmation page that counts, for that person,
exactly what is about to happen. Read it with them if you can; it is written to
be read out loud.

**What is destroyed.** Their wiki and everything under it — including the wiki
a connected consumer keeps for them — erased where it stands. It does not go to
the trash, and the window a deleted wiki normally gets does not apply. Every
fact they said about themselves goes, and so does every behaviour rule about
them: a rule is an instruction, not a memory, and handed to somebody else it
would become an instruction *about* them. Their uploaded files go, unless
somebody else uploaded the same file. Their sign-in and aliases, group
memberships, the permissions letting a consumer speak as them, the notices
waiting for them and the recent conversation window all go.

**The id is spent.** What stays behind still names them, so handing the id to a
new account would hand that person everything the memory keeps under the name.
Creating a user with that id is refused from then on; the same human coming
back gets a different id.

**What stays, because it is somebody else's memory.** Facts other people told
*about* them stay with whoever said them. *"bob did a great job on the client
presentation"* is bob's colleague's memory of their own working life, and it
does not go because bob leaves. Each such fact passes to whoever said it, and
the name stays written on it as a plain external subject — a name the memory
holds without it being anybody's account, so it gives nobody the right to read
or change anything. Facts they told about **other** people stay exactly where
they are; only the name of who said it is replaced, by an identity nobody can
hold. The record of what was done on this deployment stays, with the name
anonymised the same way.

**What this pass cannot reach.** A snapshot taken before today still holds
everything, and restoring one brings the person back whole. That decision is
yours and the page says so: open [Backup](backup.md) and delete the snapshots
from before the erasure, or keep them knowingly.

To confirm, you type the person's id. There is no undo.
